# Norway & Sweden motorhome itinerary

An Arabic, responsive itinerary for three adults travelling 19–29 September 2026, with ten distinct overnight campsites. The north-first loop visits Romsdalen, Geiranger, Loen/Olden, Sognefjord, Flåm, Voss and Hardanger, then Oslo and Stockholm. The motorhome returns at noon on 29 September, before the 16:00 flight.

[Live website](https://aldokhayel.github.io/norway-plan/) · [Full text itinerary](PLAN.md)

## Content and sources

- `trip-data.json` is the canonical itinerary: schedules, campsites, price estimates, Google-rating provenance and source links.
- `trip-data.js` and `PLAN.md` are generated by `python3 scripts/build.py`.
- `routes.js` contains OSRM road-routing snapshots dated 5 September 2026. These are ordinary car routes, not motorhome clearance or future road-condition guarantees. Ferry, boat and railway connections are explicitly schematic.
- `scripts/build-routes.py` refreshes road geometry when needed. Update its date and review the route before using a later snapshot.
- `previous-plan.html` preserves the uncommitted working plan exactly as it existed before this revision; `original-plan.html` remains unchanged.
- Campsite images link to their operator or identified travel-source pages. Historic destination images supplied in the working plan remain in `legacy-images.js`. External availability can change; failed images expose source links instead of substituting an unrelated photograph.

Most prices are planning allowances for one motorhome and three adults, not live quotes. Geiranger's September 2026 campsite tariff is explicitly sourced; Flåm's published starting price is differentiated from the final group quote. Ratings are dated snapshots from Google or named aggregators, not live feeds. No reservation has been made. The user's YouTube video could not be retrieved; no content is attributed to it.

## Local preview and validation

No package installation or API key required.

```sh
python3 scripts/build.py
node --check app.js
node scripts/validate.js
python3 -m http.server 4173
```

GitHub Pages deploys automatically when `main` is updated, using the existing `.github/workflows/static.yml` workflow. Publication continues on the existing GitHub Pages site, rather than creating an unrelated hosting destination.
