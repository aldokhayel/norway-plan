# رحلة الكرفان التفاعلية: ستوكهولم – فيوردات النرويج

برنامج رحلة كرفان تفاعلي (11 يومًا) من ستوكهولم إلى فيوردات النرويج والعودة،
19–29 سبتمبر 2026.

## المحتوى
- **`index.html`** — الخطة الجديدة: ستوكهولم إلى أوسلو مباشرة، 3 ليالٍ في فوس،
  4 ليالٍ في سترين، خريطة تفاعلية، ومحطات النوم والمرور مع مسارات خرائط Google.
- **`original-plan.html`** — نسخة محفوظة من برنامج الرحلة الأصلي قبل تعديل المسار.

## المشاهدة
افتح `index.html` مباشرة في المتصفح، أو فعّل **GitHub Pages** لعرض الصفحة عبر رابط مباشر.

> الصور والتقييمات من مساهمي خرائط Google · الرسم التوضيحي للكرفان توضيحي.
